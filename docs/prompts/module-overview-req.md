面向无背景知识的人写一篇关于各模块的中文介绍文档，帮助其快速理解该模块的核心内容。遵循以下要求：

- 优先讲解核心内容和必须要理解的点，淡化繁琐的细节或不重要的杂项（例如命令的定义等）。
- 讲清楚为什么需要该模块，输入输出，主要内容和典型场景分别是什么。
- 该文档既要让非强技术背景的人看懂，也要保留一定的专业性。
- 如果有需要，可以在文档中配图。
- 分别给三种角色提出该模块的后续学习建议：1.OpenROAD 工具使用者；2.OpenROAD 其他模块开发者；3.模块开发者。
- 文档存放在各个模块的 docs 目录下。
